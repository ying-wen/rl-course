# 强化学习：问题、方法与持续学习智能体

温颖（上海交通大学人工智能学院）的强化学习课程资料：逐页课件、各章阅读稿、课件与阅读稿 PDF、实验代码与交互演示。

- 阅读站：<https://yingwen.io/rl-course/>
- 欢迎贡献：[CONTRIBUTING.md](CONTRIBUTING.md)（提意见、勘误，或通过 PR 提交修改）
- 引用：[CITATION.cff](CITATION.cff)
- 许可：[LICENSE.md](LICENSE.md)

## 仓库结构

| 路径 | 内容 |
|---|---|
| `index.html`、`reader/`、`reading/`、`pdf/`、`code/`、`media/`、`assets/` | 阅读站本身（GitHub Pages 从本分支根目录发布），由构建生成，不要手改 |
| `pdf/` | 课件（全课与分章）与阅读稿的 PDF |
| `reader/pages/` | 逐页课件的页图 |
| `code/` | 全课与分章的实验代码压缩包 |
| `source/textbook/` | 阅读稿源文件（Markdown，每章一个），欢迎通过 PR 修改 |
| `source/tools/demos/` | 阅读稿里的交互演示（原生 JavaScript，无外部依赖），欢迎通过 PR 修改 |
| `.github/` | issue 表单与 PR 模板 |
